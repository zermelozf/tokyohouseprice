An IRR is always a return on choosing one thing instead of another, so it needs a baseline. Here each rung is measured against the rung below it, and the timing figures on each card are measured against renting ({{ res.verdict.baseline_source }}) — the counterfactual to owning at all. Assumptions — shared by both sides; edit and re-run

Land growth is entered as a spread over rent inflation, currently {{ asPct(compareAssumptions.land_spread_vs_rent) }}% + {{ asPct(compareAssumptions.rent_inflation) }}% = {{ asPct(compareAssumptions.land_spread_vs_rent + compareAssumptions.rent_inflation) }}%/yr. A positive spread means the property outgrows the rent it produces, so gross yields fall for the whole horizon — a real bet, worth making on purpose. Inflation drives rents, ownership costs and land together; the real opportunity cost is held fixed so the nominal discount rate moves with it (currently {{ asPct((1 + compareAssumptions.opportunity_cost_real) * (1 + compareAssumptions.rent_inflation) - 1) }}% nominal). Only the loan rate stays nominal — a fixed-rate mortgage is a nominal contract, and inflation eroding it is a genuine benefit of owning, not an artifact. Property tax rates: 固定資産税 1.4% + 都市計画税 0.3% on 70% of the current value, fixed in npv.py. Each buy card shows the yen amount under “how this listing was modelled”. Note the 住宅用地の特例 (⅙ / ⅓ assessment on small residential land) is not applied, so tax is overstated for a typical home.
